
# Section Context

This section introduces how to describe associations between a **categorical variable** and a **numeric variable**.

The central idea is that associations between these variable types can be summarized by **comparing conditional means** — the average value of the numeric variable within each category.

Students learn to:

1. examine the **distribution of a numeric variable**
2. compare **conditional means across groups**
3. visualize group differences using plots
4. quantify differences using **difference in means** and **Cohen’s d**

This section continues the broader theme that **associations describe patterns**, not causes.

---

# Learning Goals

By the end of this section students should be able to:

1. Recognize associations between a **categorical explanatory variable** and a **numeric response variable**.
2. Interpret **conditional means** across groups.
3. Calculate and interpret the **difference in means**.
4. Understand the purpose of **Cohen’s d** as a standardized measure of group differences.
5. Use visualizations to compare distributions across groups.
6. Connect statistical summaries to biological questions.

---

# Variables Used in Examples

The section continues using the **Clarkia RIL dataset**.

Key variables include:

**visited**

* some_visits
* no_visits

**prop_hybrid**

* proportion of seeds that are hybrids

The biological question explored is:

> Do plants receiving pollinator visits produce different proportions of hybrid seeds than plants receiving no visits?

---

# Key Concept: Grand Mean

The **grand mean** is the overall average value of a numeric variable across all observations.

Example:

Average proportion of hybrid seeds across all plants.

The grand mean represents the expected value for a **randomly chosen observation**.

---

# Key Concept: Conditional Means

A **conditional mean** is the average value of a numeric variable **within a specific group**.

Example:

```id="c1"
Mean(prop_hybrid | visited)
Mean(prop_hybrid | no_visits)
```

These values allow students to compare the **average hybrid seed proportion for plants with and without pollinator visits**.

Associations between categorical and numeric variables appear when **conditional means differ across groups**.

---

# Key Concept: Difference in Means

One simple way to summarize an association is the **difference between group means**.

Example structure:

```id="c2"
Difference in means =
Mean(prop_hybrid | visited)
-
Mean(prop_hybrid | no_visits)
```

This value measures how much the outcome differs between groups.

---

# Key Concept: Cohen’s d

**Cohen’s d** is a standardized measure of group differences.

It expresses the difference in means relative to the **pooled standard deviation**.

Conceptually:

```id="c3"
Cohen's d =
difference in means
/
pooled standard deviation
```

This allows comparisons across datasets with different scales.

Students should understand that Cohen’s d describes **effect size**, not statistical significance.

# Visualizing Categorical–Numeric Associations

Several plots help students compare numeric values across groups.

Common visualizations include:

**Histograms**

Show the distribution of numeric values.

**Density plots**

Show smoothed versions of distributions.

**Jittered scatterplots**

Reveal individual observations when points would otherwise overlap.

**Means with connecting lines**

Highlight differences between group averages.

# Common Student Confusions

### Confusing overall mean with group means

Students sometimes interpret the grand mean as representing each group.

Encourage them to distinguish:

* overall mean
* conditional means

---

### Assuming differences imply causation

Even if hybrid seed proportion differs across visitation groups, this does not prove that visitation causes the difference.

Other variables could influence both.

---

### Ignoring distribution shape

Students may focus only on means and overlook important differences in:

* variability
* skew
* outliers

Encourage students to examine full distributions.

# Tutor Guidance

When helping students:

1. Ask them to identify the **categorical variable** and the **numeric variable**.
2. Encourage them to compute or interpret **conditional means**.
3. Prompt them to describe **distribution differences**, not just means.
4. Connect statistical summaries to the **biological question about pollinator visitation and hybridization**.

Keep responses short and guide students toward interpreting patterns rather than simply calculating statistics.
