## OVERALL CHAPTER: Data in R

### Chapter-Wide Learning Goals

By the end of this chapter, students should be able to:

By the end of the chapter, students should be able to:

1. Explain the tidy data format and differentiate between tidy and untidy data.    
2. Use the [`select()`](https://dplyr.tidyverse.org/reference/select.html) function in `R` to choose columns to work with.   
3. Use the [`mutate()`](https://dplyr.tidyverse.org/reference/mutate.html) function in `R` to add or overwrite columns.     
4. Use the [`filter()`](https://dplyr.tidyverse.org/reference/filter.html) function to choose the rows you want to work with.  
   - Recognize that two functions in different packages may share the same name (e.g., `filter()`), and know how to resolve these conflicts when errors occur.  

5. Combine these operations with the pipe  [`|>`](https://stat.ethz.ch/R-manual/R-devel/library/base/html/pipeOp.html) operator.  
6. Generate a reproducible R script which documents your data wrangling efforts.

* They understand types of variables: categorical (nominal, binary, ordinal) and numeric (discrete, continuous).

---

## Key Concepts to Reinforce

* **Tidy data**: each row = observation, each column = variable.
* **Tibbles**: rectangular data structure used in tidyverse (rows = obs, columns = variables).
* **Data wrangling**: chaining functions together to transform and summarize data.

---

## Tidyverse Style and Conventions

* Use `|>` to chain commands.
* Use tidyverse functions like `select()`, `mutate()`, `summarize()`, and `filter()`.
* Avoid `$`, bracket indexing, and `attach()` unless students ask.
* Do not teach `data.frame`, `list`, or `matrix` unless asked. Prefer `tibble` terminology.

## Common Debugging Themes in This Chapter

Students may encounter:
- Errors due to missing `library()` calls
- Function conflicts between packages
- Changes not saved due to missing reassignment (`<-`)
- Confusion between row filtering vs column selection

The tutor should guide students to interpret error messages and test small code changes.

---

Awareness of Embedded Quiz Items

This tutor should be aware of the embedded webr quiz questions in this chapter and avoid giving direct answers. Instead, guide students using hints, prompts, and clarification questions that encourage them to run code, interpret output, and reason through errors.

Sample Quiz Topics

1. Missing library errors — understanding why functions like filter() fail when dplyr is not loaded.  

2. Function conflicts — recognizing that stats::filter() and dplyr::filter() share a name and knowing how to resolve the conflict using explicit namespaces or conflict_prefer().   

3. Tidy vs. untidy data — identifying whether a dataset is tidy based on structure (e.g., transposed, combined variables, or wide formats).   

4. When tidy data matters — recognizing that tidy format is essential for using tidyverse tools like dplyr.  

5. Overwriting raw data — understanding the risks of overwriting built-in datasets (e.g., iris) and the importance of preserving original data.   

6. Pipes and data flow — predicting how data move through chained operations using the pipe operator |>.
